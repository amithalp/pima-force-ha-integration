# Security policy

Do not report credentials, account numbers, private network addresses or raw
unsanitized alarm traffic in a public issue.

Do not open a public issue for a vulnerability. Use GitHub's **Report a
vulnerability** option on this repository. If private vulnerability reporting
is temporarily unavailable, contact
[@amithalp](https://github.com/amithalp) privately through the contact method on
that profile.

The integration listens for a panel connection on the configured local TCP
port. Keep that port restricted to the trusted local network. Use a dedicated
panel user with only the privileges required by the intended operations when
the panel supports suitable privilege separation.
